Sprint 0 – Projektuppstart
Sprintperiod
Start: 2026-06-07
Slut: 2026-06-07

Sprintmål
Förbereda projektet så att alla gruppmedlemmar har tillgång till utvecklingsmiljön, dokumentationen och projektets arbetsflöde innan Sprint 1 startar.

Varför är sprinten värdefull?
Sprint 0 säkerställer att hela gruppen har samma förutsättningar att arbeta i projektet. Genom att konfigurera verktyg, kommunikationskanaler och utvecklingsmiljö minskas risken för problem längre fram i projektet.

Genomförda aktiviteter
GitHub-repository gjordes tillgängligt för gruppen.
Discord användes som gemensam kommunikationskanal.
Samtliga gruppmedlemmar laddade ner och verifierade VM-testmiljön.
Projektet klonades från GitHub.
Git installerades och konfigurerades vid behov.
Dokumentationen "Kom igång med projektet" lästes igenom.
Git Workflow-dokumentationen lästes igenom.
Projektstruktur, mappar och dokumentation granskades.
Roller i projektet fördelades.
GitHub Projects, backlog och issues gicks igenom.

Resultat
Alla gruppmedlemmar fick tillgång till projektet.
Utvecklingsmiljön fungerade för samtliga.
Kommunikationsvägar etablerades.
GitHub och arbetsflödet genomgicks av gruppen.
Gruppen var redo att påbörja Sprint 1.

Identifierade risker
Viss osäkerhet kring GitHub Projects och arbetsflödet i början av projektet.
Behov av fortsatt stöd kring Git och branch-hantering för vissa gruppmedlemmar.

Sammanfattning
Sprint 0 fokuserade på att skapa en stabil grund för projektet. Gruppen säkerställde att alla hade fungerande utvecklingsmiljöer, tillgång till projektets dokumentation och förståelse för arbetsflödet i GitHub. Kommunikationskanaler etablerades och roller fördelades. Efter Sprint 0 var gruppen redo att starta utvecklingsarbetet i Sprint 1.
